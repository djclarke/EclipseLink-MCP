# Contributing to EclipseLink MCP

## File headers

Every source and config file starts with the project header. The template is
[`etc/copyright-header.txt`](etc/copyright-header.txt):

```java
/*
 * Copyright (c) 2026 Doug Clarke.
 *
 * This program and the accompanying materials are made available under the
 * terms of the Eclipse Public License v. 2.0 which is available at
 * http://www.eclipse.org/legal/epl-2.0,
 * or the Eclipse Distribution License v. 1.0 which is available at
 * http://www.eclipse.org/org/documents/edl-v10.php.
 *
 * SPDX-License-Identifier: EPL-2.0 OR BSD-3-Clause
 */
// Some portions generated by Claude.
```

Use the same text in the comment syntax of the file type:

| File type | Form |
|---|---|
| Java | the template as is, before `package` |
| XML (`pom.xml`, `eclipselink-orm.xml`) | one `<!-- ... -->` block after the `<?xml ?>` declaration, ending with `Some portions generated by Claude.` |
| YAML, `META-INF/services` files | `#` line comments |
| SQL | `--` line comments |

Not headed: Markdown docs, `LICENSE.md`, `NOTICE.md`, images, `.gitignore`, and generated output
(`samples/sales-db-generated`, and the `init` output in `samples/sales-customer`; its hand-written
`writes/` are headed). Files written by `eclipselink-mcp init` for users carry no header, because they
belong to whoever generates them.

`LicenseHeaderTest` fails the build when a file that needs the header lacks it.

## AI-authored pull requests

Every pull request authored, wholly or partly, by an AI agent must say so:

- Tick the AI-authorship box in the [pull request template](.github/pull_request_template.md) and name
  the tool (for example, Claude Code).
- Keep the disclosure in the description when the PR is edited.
- Commits made by an agent carry a `Co-Authored-By:` trailer naming it.

A person still reviews and merges every PR.
