# Third-party notices: AdventureWorks sample database

This folder contains no third-party files. `install.sh` downloads them when the database is built, and the
image built from `Dockerfile` contains the data they produce. Both are under the MIT License:

- **AdventureWorks OLTP data** (CSV files), from Microsoft's
  [sql-server-samples](https://github.com/microsoft/sql-server-samples) repository,
  release `adventureworks`, file `AdventureWorks-oltp-install-script.zip`.
- **AdventureWorks for Postgres** (`install.sql`, `update_csvs.rb`), by Lorin Thwaits,
  [lorint/AdventureWorks-for-Postgres](https://github.com/lorint/AdventureWorks-for-Postgres),
  commit `b474991f0df1c4bf55ca4735eb0254ca0709eed2`.
